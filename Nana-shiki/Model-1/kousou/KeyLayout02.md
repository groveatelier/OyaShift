# 七式（Nana-Shiki） 一型 キーレイアウト構想 #02
## Key layout について

一型は試作機の反省を踏まえたキー配置にする。 一型のキー配置があるのは試作機のおかげです。  
#02では左右親指シフトキーを日本語入力以外のキーに割り当てます。
