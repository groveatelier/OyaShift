# 七式（Nana-Shiki） 一型 キーレイアウト構想 #09
## Key layout について

三型は二型までの反省を踏まえたキー配置にする。  
#09B は #09 をベースに Tab, Backspace, Del, Enter, Ctrl, Alt の位置を
修正してみました。
