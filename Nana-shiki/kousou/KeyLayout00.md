# 七式（Nana-Shiki） 構想メモ00
## Key layout について

七式のKey Map Layoutについては、シフトキーが左右２個づつの計4個。  
加えて日英の入力モードが有るので、これで計10枚のレイヤーが存在する。  
更には CapsLock と NumLock があるので合計30枚。  
FN1/2/X も追加キーとしてあるので 60枚のレイヤーが存在可能となる。      
ここではそれらのレイヤー定義検討表になる。
