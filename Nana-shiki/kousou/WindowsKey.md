# 七式（Nana-Shiki） Windows キー操作対応  
WindowsOS と ChromeOS では日本語モードの切り替え方法が異なるので、  
キーボード側での考慮が必要になる。

## 入力モードの動作  
 
**Windows 11 の日本語 IME で「入力モード（ひらがな／カタカナ／半角／全角／英字）」を切り替えるキー操作は、すべて “IME の仮想キー (VKF1〜VKF4)” に対応している。**

---

## 🎌 **Windows IME の入力モード切り替えキー一覧（公式仕様）**

### **1. ひらがな入力（IME-ひらがな）**
- **`Ctrl + CapsLock`**  
- **`Alt + ひらがな/カタカナ`**（JISキーボード右端のキー）  
- **IME 仮想キー：`VKF3`**
- **`ひらがな/カタカナ`** (実施確認)
- **`LANG1`** (IMEヘルプ)


### **2. 全角カタカナ入力（IME-カタカナ）**
- **`Ctrl + Shift + CapsLock`**  
- **IME 仮想キー：`VKF2`**

### **3. 半角カタカナ入力**
- **`Ctrl + Shift + CapsLock` をもう一度押す場合もあり（環境依存）**  
- **IME 仮想キー：`VKF4`**

### **4. 全角英数入力**
- **`Shift + CapsLock`**  
- **IME 仮想キー：`VKF1`**

### **5. 半角英数入力（IME OFF）**
- **`CapsLock`**  
- **`Ctrl + Space`**（IME ON/OFF）  
- **IME OFF 状態は英字入力になる**
- **`LANG2`** (IMEヘルプ)

### **6. 全角カタカナ入力ー半角カタカナ入力ーひらがな入力 トグル**
- **`無変換`** (実施確認)
- **`変換`** このモード内から ひらがな入力 (実施確認)

### **6. 全角英数入力ー半角英数入力 トグル**
- **`Shift + 無変換`** (実施確認)

---

## 🌿 **かな入力 ↔ ローマ字入力の切り替え（入力方式）**
これは「入力モード」ではなく **入力方式** の切り替え。

- **`Alt + ひらがな/カタカナ`**  
→ **ローマ字入力 ↔ かな入力** を切り替える唯一の公式ショートカット。

---

## 🧩 AutoHotkey で使う場合の対応表（あなた向け）
あなたがよく使う AHK の VK コードに対応させるとこうなる。

| 入力モード | IME 仮想キー | AHK で送るキー |
|-----------|--------------|----------------|
| ひらがな | VKF3 | `Send {VKF3}` |
| 全角カタカナ | VKF2 | `Send {VKF2}` |
| 半角カタカナ | VKF4 | `Send {VKF4}` |
| 全角英数 | VKF1 | `Send {VKF1}` |

例：  
```ahk
; ひらがな
+SC1F2::Send {VKF3}

; カタカナ
+SC1F1::Send {VKF2}
```

---

## 🌸 補足：JIS キーボード特有のキー
JIS 配列ではスペース左に：

- 無変換  
- 変換  
- ひらがな/カタカナ  

が並んでいて、  
**「Alt + ひらがな/カタカナ」** が IME の入力方式切り替えに使われる。
