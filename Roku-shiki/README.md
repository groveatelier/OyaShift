# 六式（Roku-Shiki）  
親指シフト入力を、現代の環境で静かに再構築する試み

六式（Roku-Shiki）は、親指シフトキー（スキャンコード 0x1F1 / 0x1F2）を備えた  
自作キーボード用の ChromeOS と Windows の両環境で動作する  
**親指シフト入力システム**です。

「森の奥の静かな工房」で育てるように、  
小さく、静かに、長く使える道具を目指しています。

---

## 🌱 特徴

- ChromeOS（拡張機能）と Windows（AutoHotkey）で共通の入力体験  
- 既存 IME に依存しない、軽量で扱いやすい構造  
- OS ごとにフォルダを分けた、静かで見通しの良いリポジトリ構成  
- 七式（次世代版）への拡張を見据えた設計

---

## 🌳 フォルダ構成


```
Roku-shiki/
├── chromeos/   # ChromeOS 版（拡張機能）
└── windows/    # Windows 版（AutoHotkey）
```

---

## 🌲 ChromeOS 版（chromeos/）

Chrome 拡張として動作します。

- 親指シフト配列の定義  
- キーイベントのフック  
- 入力変換ロジック  
- 設定ファイル（JSON）によるカスタマイズ

詳しくは `chromeos/README.md` を参照してください。

---

## 🌲 Windows 版（windows/）

AutoHotkey（AHK）で動作する Windows 版です。

- IME に依存しないキー変換  
- 親指シフトの同時押し判定  
- 配列のカスタマイズが容易  
- 軽量で常駐負荷が小さい

詳しくは `windows/README.md` を参照してください。

---

## 🌾 今後の予定（七式への布石）

- キーボード側で親指シフトを完結させる構成  
- Column-staggered（コラムスタッガード）  
- Trackball 搭載  
- エンジンに RP2040 を採用  

六式は “シリーズ六作目で漸く形になった最初の一歩” であり、  
七式はその先にある **静かで強い入力エンジン**を目指します。
