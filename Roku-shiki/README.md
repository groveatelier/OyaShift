# 六式（Roku-Shiki）  
親指シフト入力を、現代の環境で静かに再構築する試み

六式（Roku-Shiki）は、親指シフトキー（スキャンコード 0x1F1 / 0x1F2）を備えた  
自作キーボード用の ChromeOS と Windows の両環境で動作する  
**親指シフト入力システム**です。

「森の奥の静かな工房」で育てるように、  
小さく、静かに、長く使える道具を目指しています。

---

## 🌱 特徴

- ChromeOS（拡張機能）と Windows（AutoHotkey）で共通の入力体験  
- 既存 IME に依存しない、軽量で扱いやすい構造  
- OS ごとにフォルダを分けた、静かで見通しの良いリポジトリ構成  
- 七式（次世代版）への拡張を見据えた設計

## 🌳 六式（Roku-shiki）について

六式は、  
自作キーボードの親指シフトキー（SC1F1 / SC1F2）と連携し、  
ChromeOS と Windows の両方で動作する  
**静かで軽い親指シフト入力エンジン**です。

- ChromeOS 版：独自 IME（六式 IME）を内蔵  
- Windows 版：システム IME と連携し、かな生成のみ担当  
- 自作キーボード向けに最適化  
- quietgrove の世界観に基づく、長く使える設計

詳細は各 README を参照してください。

- `Roku-shiki/chromeos/README.md`
- `Roku-shiki/windowsos/README.md`

## 📘 **ハードウェア要件（Hardware Requirements）**

六式（Roku‑shiki）は、**「親指シフト専用の物理キーを備えたキーボード」** を前提としています。

---

### **親指シフトキー (Thumb Shift Keys)**
六式は以下の 2 つのスキャンコードを親指シフトキーとして扱います。

| 役割 | Scan Code | 説明 |
|------|-----------|------|
| 左親指キー | `SC1F1` | 左手親指で押すシフトキー |
| 右親指キー | `SC1F2` | 右手親指で押すシフトキー |

これらは一般的なキーボードには存在しないため、自作キーボードが前提となります。
とはいえ、六式では親指シフトキーの制御を OS 上のソフトウェア側で行っているため、
QMK / VIA / 独自ファームウェアの知識がなくても、**市販の安価な USB キーボードの制御基板を利用して実現することができます。**  
3D プリンターをお持ちであれば、ご自身の手に合わせた形状で親指シフトキーを設計し、完成させることも可能です。

### **物理レイアウトの推奨（Recommended Physical Layout）**
六式実現にあたって私は、以下のような物理配置としました。
- 基本配列は US キーボード配列
- 左親指キー：C, V キー下側 (本来のスペースキーの左側に相当) 
- 右親指キー：N, M キー下側 (本来のスペースキーの右側に相当)
- どちらも **単独押し（空白）** と **同時押し（シフト）** を区別できる  
- キーキャップは親指で押しやすい形状かつ少し高めにするのが望ましい
- スペースキー：左右親指キーよりも手前側に配置

### **3Dプリンターモデル（3D Printer Models）**
六式用に設計したキーボードケースおよび親指キー周辺パーツの .stl ファイルを
リポジトリにアップしています。自作の際の参考にどうぞ。

- キースイッチは一般的なメカニカルキースイッチを使用
- Function キーや Volume キー等は 6mm 角のタクトスイッチを使用
- 3D プリンターの制約上、左右別パーツ構成
- キートップのデータは含まれていないため、ご自身で準備してください

### **ChromeOS / Windows での扱いの違い**
- **ChromeOS 版（六式 IME）**  
  キーボードイベントを直接フックし、  
  親指キーの同時押し判定も IME 内部で処理します。

- **Windows 版（AutoHotkey）**  
  AHK がスキャンコードを受け取り、  
  親指キーの同時押し判定はハードウェア側（キーボードファームウェア）が担当します。  
  六式は **かな生成のみ** を行います。

## 使い方（Usage）

六式は、専用の親指シフトキー（SC1F1 / SC1F2）を使って入力する独自方式の日本語入力エンジンです。
- 親指シフトキーは スペースキーとは別物  
（単独押しはスペースとして扱いません）
- 日本語／英語の切り替えは
Shift キー ＋ 親指シフトキー の組み合わせで行います
→ 六式固有の仕様です

    | 入力切り替え | キー操作 |
    |------|-----------|
    | 英文字 | Shiftキー ＋ 左親指シフトキー |
    | 日本語 | Shiftキー ＋ 右親指シフトキー |

- かな入力は一般的な親指シフト配列に準拠
- ChromeOS / Windows のどちらでも同じ操作感で利用できます
