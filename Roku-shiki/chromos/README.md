# 六式（Roku-Shiki）ChromeOS 版  
親指シフト入力を ChromeOS 上で静かに実現する拡張機能

六式（Roku-Shiki）ChromeOS 版は、  
自作キーボードに搭載した親指シフトキー（スキャンコード 0x1F1 / 0x1F2）と連携し、  
ChromeOS 上で **独立した親指シフト入力エンジン**として動作します。  
また親指シフトキーボートが手元に無く、JISキーで親指シフトを実現する為に  
Multi-tapと長押しを認識する機能も有しています。 

IME に依存せず、  
「森の奥の静かな工房」で育てるように、  
小さく、静かで、長く使える入力環境を目指しています。

---

## 🌱 機能

- キーイベントのフックと変換処理
- 左右親指キーとの同時押し判定  
- 複数回タップと長押し判定 
- Chrome 拡張としての軽量な常駐動作

---

## 🧩 六式 ChromeOS 版の入力方式について

六式 ChromeOS 版は、ChromeOS の標準 IME を利用せず、  
**キーボード入力を直接フックして独自の IME を内部に実装**しています。

- `keydown` / `keyup` を監視  
- 親指キー（0x1F1 / 0x1F2）との同時押しを判定  
- スペースキーとの同時押しを判定
- 文字キーの長押しを判定
- スペースキー押下中の文字キーマルチタップを判定
- JavaScript 内で変換ロジックを実行  
- `chrome.input.ime.commitText()` により文字列を注入  

この方式により、  
ChromeOS 上で六式独自の軽量で静かな入力体験を実現しています。

---

## 🧩 六式 ChromeOS 版の入力仕様について

六式 ChromeOS 版の入力は、基本的に親指シフト配列のキーボードに  
準拠しています。 以下の点に注意していれば、親指シフトのフィーリングを  
十分に楽しむことができます。  

- 日英入力モードの切り替え: 左Alt - 英モード，右Alt - 日モード  
Altキーは二度押しが必要な場合もあります。
- 小指のシフトキーを押して文字キーを押下した場合:   
英大文字の入力になります。その後は英文字が入力され続けます。  
日モードに戻すには、スペースキーを押したまま文字キーを複数回   
タップして日文字を選択することで日文字モードに戻ります。  
もしくは右Altキーを複数回押して日モードに戻して下さい。  
- JISキーの場合はスペースとキーが左右親指キーの代わりに機能します。  
濁音の入力はほんの少し文字キーを長押しすることで実現しています。  
- スペースキーを押したまま文字キーを複数回タップすることで文字を  
切り替えることもできます。  
親指シフト、長押し、マルチタップのそれぞれの入力方法を使って  
文字の入力を可能にした独特の入力フィーリングになっています。

## 🌲 インストール方法（開発者モード）

1. Chrome の設定 → 「拡張機能」  
2. 右上の「デベロッパーモード」を ON  
3. 「パッケージ化されていない拡張機能を読み込む」  
4. `chromeos/OyaShift/`または`chromeos/Multi-tap/`フォルダを選択

読み込むと、六式の入力エンジンが ChromeOS 上で動作を開始します。

## 🌾 カスタマイズ

### キーイベント処理  
`RokushikiIME.js`,`GranShiftBG.js` 内のロジックを編集することで、  
変換ルールや同時押し判定の調整が可能です。  

### 辞書ダイアログ  
`dictdlg.js` と `dictdlg.html` を編集することで、辞書登録 UI の  
動作を変更できます。
