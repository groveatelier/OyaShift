# 六式（Roku-Shiki）Windows 版  
AutoHotkey で実現する静かな親指シフト入力エンジン

六式（Roku-Shiki）Windows 版は、  
自作キーボードに搭載した親指シフトキー（スキャンコード 0x1F1 / 0x1F2）と連携し、  
Windows 上で **親指シフト配列を生成する入力エンジン**として動作します。

ChromeOS 版とは異なり、  
Windows 版は **システム標準の IME（Microsoft IME / Google 日本語入力など）をそのまま利用**します。  
六式は “かな入力の生成” を担当し、  
漢字変換は OS の IME に任せる構造になっています。

「森の奥の静かな工房」で育てるように、  
小さく、静かで、長く使える入力環境を目指しています。

---

## 🌱 機能

- AutoHotkey（AHK）による軽量な常駐動作  
- 親指キー（左右）の同時押し判定  
- IME に依存しない独立した文字変換  
- ChromeOS 版と近い入力体験を提供

---

## 🧩 六式 Windows 版の入力方式について

六式 Windows 版は、  
Windows の IME を置き換えるのではなく、  
**AutoHotkey でキーボードイベントをフックし、  
親指シフト配列に基づく “かな入力” を生成する仕組み**です。

- 親指キー（0x1F1 / 0x1F2）を検出  
- 通常キーとの同時押しを判定  
- AHK スクリプト内でかな文字を生成  
- `Send` により IME に文字を渡す  
- **漢字変換は IME が担当**

ChromeOS 版とは異なり、  
Windows 版は **IME を自前で持ちません**。  
そのため、OS の IME と自然に連携し、  
既存の変換辞書や学習機能をそのまま活かせます。

```
├── JisShift.ahk         # 旧版エンジン（SC07D/073 対応）
├── SpaceShift.ahk       # 親指シフト入力エンジンのプロトタイプ
└── README.md            # このファイル
```

---

## 🌲 使い方

1. AutoHotkey v2 をインストール  
2. `OneFxShift.ahk` を実行  
3. タスクトレイに常駐アイコンが表示されれば準備完了  
4. 親指キーと通常キーの同時押しで “かな入力” が生成され、  
   **漢字変換は IME が行います**

## 🌾 カスタマイズ

### 変換ロジック

変換ルールや同時押し判定の調整が可能です。
